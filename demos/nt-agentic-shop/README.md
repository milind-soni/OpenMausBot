# เดโม NT Agentic AI: สั่งเมาส์ไร้สายออนไลน์

บอทใน OpenMausBot คุยกับลูกค้า แล้วเรียกใช้ระบบหลังบ้านจำลอง 5 ระบบผ่าน MCP:
สต็อกและราคา, คำสั่งซื้อ, ชำระเงิน, คลังสินค้า, ขนส่ง
หน้า Back office แสดงทุกการเรียกของ AI แบบเรียลไทม์ ใช้เปิดบนจอที่สองตอนนำเสนอ

ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node 18 ขึ้นไป ข้อมูลอยู่ในหน่วยความจำ ปิดเซิร์ฟเวอร์แล้วหายหมด

## 1. เปิดระบบหลังบ้าน

```bash
node demos/nt-agentic-shop/server.mjs
```

- Back office: http://127.0.0.1:8787/
- MCP: http://127.0.0.1:8787/mcp

ถ้าจะให้ลูกค้าเปิดลิงก์ชำระเงินจากมือถือในวง Wi-Fi เดียวกัน:

```bash
HOST=0.0.0.0 PUBLIC_URL=http://192.168.1.50:8787 node demos/nt-agentic-shop/server.mjs
```

(เปลี่ยน `192.168.1.50` เป็น IP ของเครื่อง) ตัวแปร `SHIP_STEP_SECONDS` (ค่าเริ่ม 20)
คือเวลาที่พัสดุขยับไปทีละขั้น

## 2. ต่อเข้า OpenMausBot

1. **Plugins → MCP servers → Add server** วาง `http://127.0.0.1:8787/mcp`
   ตั้งชื่อ `nt-shop` ต้องขึ้น *Connected: 6 tools*
2. สร้างบอทใหม่ ชื่อ **น้อง NT** วางเนื้อหา [persona.md](persona.md) เป็นคำสั่งของบอท
3. ใน **Access** ของบอท เลือกให้ใช้ `nt-shop` ได้
4. แนะนำให้ตั้ง Approval ของบอทเป็นแบบไม่ต้องถามทุกครั้ง ให้เดโมลื่น

## 3. สคริปต์นำเสนอ (ตามภาพ 4 ขั้น)

| ลูกค้าพิมพ์ | AI ทำ (ดูได้ใน Back office) |
| --- | --- |
| มีเมาส์ไร้สายไหมคะ ราคาเท่าไหร่ | `check_product` → ฿599 เหลือ 42 ชิ้น พร้อมส่ง |
| เอา 1 ชิ้นค่ะ ส่งที่ สมศรี ใจดี 081-234-5678 99 ถ.แจ้งวัฒนะ แขวงทุ่งสองห้อง เขตหลักสี่ กรุงเทพฯ 10210 | `create_order` → `create_payment_link` ส่งลิงก์ |
| (กดลิงก์ จ่ายในหน้า NT Pay) โอนแล้วค่ะ | `check_payment_status` → `send_to_warehouse` ได้เลขพัสดุ |
| พัสดุถึงไหนแล้วคะ | `track_shipment` → ตำแหน่งล่าสุด และกำหนดส่ง |

ลูกเล่นเพิ่ม:

- ถาม "มีรุ่นเสียงเงียบไหม" รุ่น S2 สต็อกหมด AI จะเสนอรุ่นที่มีของ
- พิมพ์ "โอนแล้ว" ก่อนกดจ่ายจริง AI ตรวจแล้วจะบอกว่ายังไม่ได้รับเงิน ไม่ส่งคลัง
  (ระบบคลังปฏิเสธเองด้วย แม้ AI จะพยายาม)
- กด **เลื่อนสถานะ ▶** ใน Back office เพื่อเร่งพัสดุก่อนถามรอบถัดไป
- **รีเซ็ตเดโม** ล้างทุกอย่างก่อนรอบใหม่
