## Download a released build

Published installers appear in [Edu Bot releases](https://github.com/EduardoMoraga/edu-bot/releases). Choose the package for your operating system and processor. You can also build from source using the steps below.

## Install an agent CLI

Edu Bot needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart Edu Bot.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/EduardoMoraga/edu-bot.git
cd edu-bot
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

Edu Bot stores its application data under `~/.openmausbot`. Workspaces you add are in `~/.openmausbot-profiles/`; once this computer's bots have moved to My Cloud, This Mac's (or This PC's) is there too, as `default`, and `~/.openmausbot` keeps the copy from before the move. On a server, see [Data and backups](/docs/self-hosting/data-and-backups) for the Docker and installer folders. Electron window and browser data use the normal per-platform application data directory.
