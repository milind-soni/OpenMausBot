---
title: Desktop updates
description: Check your Edu Bot version and install a release.
icon: RefreshCw
---

Automatic updates are off by default. Open **Settings → App** to see the installed version. Download published builds from [Edu Bot releases](https://github.com/EduardoMoraga/edu-bot/releases).

Quit Edu Bot before installing the new build. Your conversations and settings live in the app's data directory, outside the application bundle.
