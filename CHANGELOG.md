- Added an animated welcome, local profile, AI engine checks, and an editable goal-based Buddy team.

- Improved desktop Preview navigation and the schedule list.

- Removed cloud computers. Bots can still use this computer in the desktop app and connected apps. Bots that used the removed engine switch to the default model and receive a chat notice.

- Added usage-left rings with accessible details and display settings. Codex can show live readings; AI apps without verified readings show an unknown amount.
