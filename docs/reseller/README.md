# Reselling OpenMausBot

One server is one reseller. Each customer gets a private workspace with your
logo, your name and a web address you choose, and you pay the vendor by
workspace and by user while setting your own price.

- [Install on a VPS](install-vps.md): one script from a blank server to the first workspace.
- [Workspaces and web addresses](workspaces.md): the default address, a customer's own domain, DNS.
- [Branding](branding.md): logo, name, accent, support link and sign-in mail.
- [Billing](billing.md): wholesale and retail rates, and the monthly usage report.

The offline checks and the real-server recipe are in
[the verification record](../verification/white-label-reseller.md).
