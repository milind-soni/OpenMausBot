## The number worth knowing

Deferred tool loading takes about 10,000 input tokens off every Claude call on a bot with the agents tools
mounted: the tool schemas the proxy advertises were costing more than the harness's own prompt. It is off
by default in this PR because it adds one `search_tools` step when a rare tool is needed; the live run shows
Claude taking that step correctly.
