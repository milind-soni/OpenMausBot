editors, authors, scientists, researchers, and developers.

|---|---|

| [Usage left](usage-and-limits.md) | The rings at the top of the window: how much each AI app has left and when it refreshes |
| [Schedules](schedules.md) | Have a Buddy start work at a set time, like an alarm clock |
| [Backup model](backup-model.md) | What happens when an AI model's usage runs out |
| [Preview](preview.md) | Check web pages and files at phone, tablet, and desktop sizes |
| [Glossary](glossary.md) | The plain words the studio uses, and what they replace |

For maintainers: [copy-sweep.md](copy-sweep.md) lists wording changes that are
waiting to be applied in the app. Guides are updated together with the feature
they describe. Plans live in `docs/dev/plans/`, and task status lives in
`docs/dev/fixes/`.
