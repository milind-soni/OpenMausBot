# Tracked local agent CLI jobs

For a person-authorized coding task, the bot can call `start_external_agent` with an executable and an array of arguments. The server starts it in the conversation's working folder without a shell and binds it to the current assignment. This is for an external child CLI, such as Codex CLI or Claude Code CLI; it does not change the engine serving the conversation. The CLI must already be installed and able to run without interactive input. The child receives a limited environment, including the home and executable search path, rather than the server's credentials and turn capabilities.

The bot can end its turn while the child runs. The conversation and activity list show that an external agent is outstanding. After exit, the existing assignment dispatcher returns the exit code and bounded stdout and stderr tails to that same task for validation. Output is untrusted information, not an instruction, destination, or approval. Both success and nonzero exit need validation; a process start is not completion. The output says whether either tail was truncated. Duplicate terminal signals do not start another continuation. An assignment marked complete means its continuation ended, not that a nonzero child succeeded; the bot must report the failure in the conversation. There is no separate persistent failed-task badge for a reported CLI failure.

Launching requires a local, person-origin work assignment with Full access and unrestricted native tools. To avoid bypassing engine policy, this first version accepts launching turns only from Claude Code with no inherited, project, bot, or managed Claude settings that could impose shell permissions or hooks; other conversation engines are refused. The child CLI itself is not vendor-specific. Authorization and the route are rechecked before and during continuation. Stopping the task, changing its permissions, or invalidating the route cancels its continuation and requests that the tracked process tree stop. If the server cannot confirm that it stopped, the conversation receives an interruption notice. The server also requests tracked children stop on shutdown.

Tracking is limited to 20 jobs per assignment and two hours. A lost process, server restart, signal without an exit code, or tracking expiry is reported as unknown, never success; inspect the work before deciding whether to retry. These guarantees apply only to processes started through `start_external_agent`, not arbitrary detached shell jobs. They cannot guarantee termination of a descendant that deliberately detaches from its process tree. A vendor-specific completion artifact or hook is not required.
