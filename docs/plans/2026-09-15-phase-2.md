## Why this order

The task object is the seam everything else in the phase attaches to (results, budgets,
fallbacks, run records), and #1185 already carries its hardest part with tests. Reliability
before tools because a fallback ladder and honest tool errors change what every later bench
number means. Tools before the ask/unattended items because deferred loading changes the
prompt every engine sees and must be measured alone.
