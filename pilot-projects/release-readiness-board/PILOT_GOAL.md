# Goal：发布验收看板钉钉协作试点

## 范围

在本仓库内维护“发布验收看板”。首批可写范围为 `app/**` 与 `tests/**`；文档和依赖变更需由 Owner 单独授权。

## 不变量

- 始终为非生产、静态演示数据。
- 不接入网络、数据库、身份系统或第三方服务。
- 不读取或新增任何 Secret、Token、Webhook、个人联系方式。
- 不删除既有验证断言来换取测试通过。
- 不修改 OpenMausBot 控制服务、Ledger 或唯一 Owner 配置。
- 所有控制动作仍只能由唯一 Owner 执行。

## 验证

```bash
node --test tests/source-contract.test.mjs
```

由 Codex 完成基线验收时额外运行：

```bash
npm test
npm run lint
```

## 预算

单个钉钉需求限定为一个可观察界面能力，建议最多修改 8 个文件、执行 3 次验证；超过范围时停止并请求 Owner 拆分。

## 收束

每个需求必须输出：

- 已完成的用户可见变化
- 修改文件
- 验证结果
- 未完成或失败项
- 下一步建议
