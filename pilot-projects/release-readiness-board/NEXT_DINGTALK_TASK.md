# 第一条钉钉完善需求

在基线工程接入钉钉后，发送：

```text
@研发助手 创建非生产 UI 测试任务：在 Release Room 的发布检查清单中增加优先级筛选（全部、P0、P1、P2）。优先级筛选必须能与现有状态筛选和搜索同时生效；没有结果时继续显示现有空状态。只允许修改 app/** 和 tests/**，不得新增网络请求、依赖或真实数据。验收：离线源契约测试通过，并在结果中说明修改文件和测试证据。
```

预期效果：

1. 工具栏出现优先级筛选。
2. 选择 P0 时只显示 P0 检查项。
3. 再选择“阻塞”时只显示同时满足 P0 与阻塞的检查项。
4. 搜索继续与两个筛选条件组合生效。
5. 不修改基线静态数据，不新增外部依赖。
