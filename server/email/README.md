EMAIL_SEND_MESSAGE requires text for plain-text compatibility. html optionally adds a multipart alternative. inline_images accepts at most four objects containing only cid (unique ASCII identifier, 1–128 characters) and data_base64 (canonical PNG bytes). Decoded bytes total at most 1 MiB. Reference an image with <img src="cid:logo">. File paths, URL attachments, raw MIME and arbitrary headers are not accepted. Composition disables file and URL access. Existing send approval, audit, recipient, reply and Sent-copy behavior remains in the host/client path. filed=false means sending succeeded but filing did not.

Offline acceptance: run vitest on server/email/. Tests use synthetic PNG bytes and fake SMTP/IMAP dependencies, including the native host-to-client path. Keep OMB_EMAIL_REAL_TEST unset unless a dedicated local test mail server was explicitly prepared.
