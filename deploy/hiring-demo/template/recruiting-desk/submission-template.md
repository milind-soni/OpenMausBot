# Client submission template (Submission Writer)

Subject: `Submission: <Full name> - <Role> (<REQ id>)`

```
Hi <client contact first name>,

Please find <Full name> for the <Role> role (<REQ id>).

Name: <Full name>
Email: <email>
LinkedIn: <LinkedIn URL>
Notice period: <n weeks / none>
Availability: <earliest start>
Bill rate: $<rate>/hr <C2C or W-2>
Education: <degree, school>
Work authorization: <USC / GC / H-1B / H-4 EAD / OPT> (copy attached)

Why <first name>:
- <must-have match with evidence, e.g. "11 yrs Java; owns Spring Boot claims services on AWS EKS">
- <the client's nice-to-have, e.g. "6 yrs healthcare payer domain">
- <screen highlight, e.g. "available Nov 10, hybrid Tue-Thu confirmed">

Resume and work authorization attached. RTR on file.

Best,
Recruiting Desk
```

Rules:
- Every field above is required. If `draft_submission` lists missing fields, report them; don't invent values.
- Bill rate is the client's max unless the Desk Manager says otherwise.
- Three short "why" bullets, each with evidence. No adjectives without facts.
